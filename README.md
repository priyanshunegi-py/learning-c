# Learning C
Welcome to my repository where i share and track my progress learning C programming!

## Projects
### 1. Number Guessing Game (`/guessthenumber`)
This is a dynamic terminal game I made as my first project from scratch.

* **Features:**
  * Tracks total guess attempts.
  * Uses `srand()` and `time()` to generate unique random number every time you run the program.
  * Dynamic feedback loop: Tells the player if they are getting closer "HOT" OR farther "COLD" relative to their previous guess.
